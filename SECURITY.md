# Security Policy

## Supported versions

Only the latest version on the `main` branch is currently supported with security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Use GitHub's private security advisory feature for this repository when available. Include:

- a clear description of the vulnerability;
- affected files, commands, or versions;
- reproducible steps or a proof of concept;
- the potential impact and any suggested mitigation.

We will acknowledge valid reports, investigate them, and coordinate disclosure after a fix is available.

Never include API keys, tokens, or other secrets in a report.
